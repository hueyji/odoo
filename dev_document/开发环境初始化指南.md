# Odoo 16.0 开发环境初始化指南

> 场景：本地 Mac/Linux 开发者在仓库根目录 `/Users/shawnmacmini/code/odoo-16.0` 使用项目自带 `.venv`，连接共享 PostgreSQL 数据库并运行 Odoo 实例。

## 1. 系统依赖

- Python 3.10.x（`/usr/bin/python3 --version` 验证）  
- PostgreSQL 13 或 14，启用 `odoo` 超级用户  
- Node.js 16 LTS（用于编译 OWL、SCSS，建议使用 `nvm` 管理）  
- wkhtmltopdf 0.12.6（带 Qt 补丁），用于报表导出  
- 工具：`psql`、`npm`、`yarn`、`lessc`

## 2. 虚拟环境激活与依赖安装

```bash
cd /Users/shawnmacmini/code/odoo-16.0
source .venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt
```

- 如需开发附加模块，额外安装包请写入 `requirements.txt` 并在 PR 说明。  
- `pip list --format=freeze > requirements.lock` 可生成临时锁定文件，提交前请删除以保持仓库整洁。

## 3. 数据库与配置

1. 创建数据库用户与库（仅首次）：
   ```bash
   psql -U postgres -c "CREATE ROLE odoo WITH LOGIN PASSWORD 'odoo' SUPERUSER;"
   createdb -U odoo brand_multistore_dev
   ```
2. 复制模板配置：
   ```bash
   cp odoo.conf odoo.conf.local
   ```
3. 在 `odoo.conf.local` 中确保以下关键项：
   ```
   [options]
   db_host = 127.0.0.1
   db_port = 5432
   db_user = odoo
   db_password = odoo
   addons_path = addons,addons-custom
   data_dir = ~/.local/share/Odoo16
   log_handler = :INFO
   longpolling_port = 8072
   workers = 0  # 开发模式使用单进程
   ```
4. 共享数据库：统一默认库名 `brand_multistore_dev`。如需自建分支数据库，命名规则 `brand_multistore_<功能缩写>` 并在群内登记。

## 4. 启动与常用命令

```bash
# 开发模式（带自动重载、调试）
./odoo-bin --config=odoo.conf.local -d brand_multistore_dev --dev=all --limit-time-real=120

# 启动长轮询服务（消息总线）
./odoo-bin gevent --config=odoo.conf.local -d brand_multistore_dev --longpolling-port=8072

# 更新指定自研模块
./odoo-bin -c odoo.conf.local -d brand_multistore_dev -u brand_core,store_inventory

# 运行单元测试
./odoo-bin -c odoo.conf.local -d brand_multistore_dev --test-tags store_inventory --stop-after-init
```

- 日志输出位于仓库根目录 `odoo.log`，调试时可在命令增加 `--log-level=debug_rpc`.  
- 连接共享数据库时，请勿使用 `-i base` 重新初始化，以免影响他人。

## 5. 前端构建

```bash
npm install -g less less-plugin-clean-css
npm install --global rtlcss
./odoo-bin -c odoo.conf.local -d brand_multistore_dev --dev=assets
```

- OWL 组件建议放在自研模块 `static/src/components/`，通过 `__manifest__.py` 的 `assets` 注册。  
- SCSS 修改后运行 `--dev=assets` 或执行 `./odoo-bin build_assets` 重新打包。

## 6. IDE / Lint 建议

- 使用 VS Code + Pylance，启用 `.vscode/settings.json` 中的 `python.analysis.extraPaths` 指向 `odoo`.  
- 安装 Odoo Lint (`pip install pylint-odoo`) 并在保存时自动运行。  
- 推荐启用 `black` + `isort` 作为 pre-commit 钩子；配置稍后在质量保障任务中统一。

## 7. 常见问题

- **无法连接数据库**：确认 `pg_hba.conf` 开启本地连接，或在 `psql` 中执行 `ALTER ROLE odoo WITH SUPERUSER;`。  
- **模块安装失败**：确认模块路径存在于 `addons_path`，并在 `__manifest__.py` 中正确声明依赖。  
- **长轮询报错**：确认已使用 `gevent` 命令启动第二个进程，或在 Nginx 反向代理中开启 WebSocket/longpolling 转发。  
- **翻译不生效**：访问 `/web?debug=assets` 后清缓存，或使用 `./odoo-bin --dev=reload` 重新加载。
